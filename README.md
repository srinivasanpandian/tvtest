# TV Display System

A simple web-based system for displaying images and videos in a loop on a TV screen.

## Setup Instructions

1. Place your media files in the `media` folder:
   - Images: .jpg, .png formats
   - Videos: .mp4 format

2. To view on a TV:
   - Connect your computer to the TV via HDMI
   - Open index.html in a modern web browser (Chrome recommended)
   - Press F11 for fullscreen mode

## Features
- Automatic rotation between images and videos
- Images display for 4 seconds each
- Videos play completely before moving to next item
- Optimized for 1920x1080 resolution
- Smooth transitions between media
- Muted video playback

## Customization
- Adjust timing in script.js
- Add media files to the media folder
- Configure transitions in styles.css
